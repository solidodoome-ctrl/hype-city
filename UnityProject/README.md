
# HYPE CITY — Unity Project

## Game information
- Engine: Unity 6 LTS
- Graphics: Universal Render Pipeline (URP)
- Platforms: Android and iOS
- Multiplayer: Shared online city
- Camera: Third-person
- Character style: Realistic 3D

## Main features
- Character creation
- Hairstyles and hair colors
- Open-world city
- Cars and motorcycles
- Jobs and businesses
- Police and emergency services
- Online multiplayer
- Cross-platform Android and iOS play

## Development stages
1. Create Unity project.
2. Build player movement and camera.
3. Create the first city environment.
4. Add character customization.
5. Add vehicles and roleplay activities.
6. Implement shared multiplayer.
7. Optimize and test Android and iOS.

This is an original game project. Use original or properly licensed assets and code.
