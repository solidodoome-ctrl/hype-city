
# HYPE CITY - Multiplayer Development Plan

## Goal
Create one shared online roleplay world where Android and iOS players can play together.

## Multiplayer features
- Shared player sessions
- Player names and profiles
- Real-time character movement
- Chat and social interaction
- Player appearance synchronization
- Jobs and activities
- Vehicles and ownership
- Businesses and properties
- Police and emergency roleplay

## Technical direction
- Game engine: Unity 6 LTS
- Rendering: Universal Render Pipeline (URP)
- Target platforms: Android and iOS
- Multiplayer networking: Evaluate Photon Fusion and Unity Netcode for GameObjects
- Server hosting: Dedicated authoritative game servers
- Database: Persistent player accounts, inventory, money, and progression

## Security requirements
- Validate money and inventory changes on the server
- Validate jobs, permissions, and player actions
- Add reporting, blocking, and moderation tools
- Protect accounts and saved player data

## Development stages
1. Build a small playable 3D city.
2. Finish character movement and camera.
3. Add mobile controls and customization.
4. Connect multiplayer networking.
5. Test Android and iOS players together.
6. Add roleplay systems and expand the city.
7. Optimize and prepare for release.

## Initial performance target
Design and benchmark small multiplayer sessions first.
A target of 32-64 players per server instance is a future testing goal, not a guaranteed capacity.

## Important
All maps, characters, code, logos, and user interface assets must be original or properly licensed.
